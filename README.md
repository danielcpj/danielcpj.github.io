## Publish for free with GitHub Pages

1. Sign in to GitHub and create a **public** repository called `YOUR-USERNAME.github.io`, replacing YOUR-USERNAME with your exact GitHub username.
2. Choose **Add file → Upload files**. Upload the CONTENTS of this folder: index.html, style.css, script.js, and the assets folder. Keep index.html at the repository root (do not upload the enclosing figure-portfolio folder or the ZIP).
3. Commit the upload. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for GitHub's deployment to finish, then use the URL shown in Pages settings, normally https://YOUR-USERNAME.github.io/.
6. Open the link in a private browser window to check public access and figure loading.

Official guide: https://docs.github.com/en/pages/quickstart

## Editing

Update the text in index.html and visual styling in style.css. Upload changed files to update the published site. No installation or build command is required.
